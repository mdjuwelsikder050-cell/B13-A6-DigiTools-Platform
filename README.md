Project Name: Digital Tools Store
A modern and responsive web application where users can explore, purchase, and manage premium digital tools. Built with a focus on smooth user experience, clean UI, and efficient state management.

Description
This project is a fully functional digital tools platform that allows users to browse products, add them to a cart, and simulate a checkout process. It features a clean UI, responsive design, and real-time user feedback using toast notifications.

Technologies Used
React.js Tailwind CSS React Toastify JavaScript (ES6+) Vite

Features
Add to Cart System – Users can add and remove items with real-time updates and notifications

Toast Notifications – Instant feedback for actions like adding, removing, and checkout

esponsive Design – Fully optimized for mobile, tablet, and desktop devices
